## 1. Контроль дубликатов задач по файлам

- В конце функции process_task в py/ai_image_processor.py добавить удаление файла задачи из папки tasks после успешной обработки или ошибки. Это гарантирует, что задача не будет обрабатываться повторно при каждом запуске крона, даже если force=true.
- Пример:
  ```python
  # После записи результата
  if os.path.exists(task_path):
      os.remove(task_path)
  ```
