# План развертывания AI Product Image Project на боевом хостинге

## 📋 Аудит текущего состояния проекта

### ✅ Что работает корректно:
- **Основной пайплайн обработки**: удаление логотипов через RunwayML, удаление фона, композиция
- **Интеграционные тесты**: проходят успешно, поддерживают обработку изображений с расширениями .png и .jpg
- **Архитектура**: четкое разделение WordPress-плагина и Python-скриптов
- **Логирование**: детальная диагностика всех этапов

- Интеграция с WooCommerce **не реализована** (требуется доработка)

- Админ-интерфейс отсутствует
- Функционал ограничен базовыми классами

#### 2. **Временные файлы и скрипты**
- Скрипт очистки (py/cleanup_production.py) **отсутствует** — требуется реализовать
- DEPLOYMENT_README.md **отсутствует**
- Тестовые ассеты и интеграционные тесты поддерживают оба расширения (.png, .jpg)

#### 3. **Конфигурация**
- Хардкод путей в config.yaml
- Нет разделения dev/prod конфигураций
- Переменные окружения не используются

#### 4. **Безопасность**
- API-ключи не должны попадать в логи
- Не реализовано маскирование ключей
- Нет ротации логов
